# Task: Add Reading Home

## Summary

Build the initial reading home screen for the Juyaro Bible Project.

## Background

Users should be able to open the app and quickly begin QT without complex navigation.
The reading home is the entry point for the core experience and should make it easy to start a 5-minute, 10-minute, or 30-minute QT session.

This screen should reflect the product principle of “start immediately with minimal friction.”

## Goals

* Create the first reading home screen
* Allow users to choose a QT duration
* Make the app’s primary action obvious
* Establish the entry point for the reading flow

## Non-Goals

* Full memo UI
* Full reflection question UI
* Community/group feed UI
* Advanced personalization

## Deliverables

* Reading home screen
* Duration selection options:

  * 5 minutes
  * 10 minutes
  * 30 minutes
* Primary CTA to start reading
* Basic responsive layout for PWA use

## Acceptance Criteria

* The user can land on the reading home and understand the main purpose immediately
* The user can choose between 5, 10, and 30 minute QT options
* The screen works on both mobile and wider layouts
* The screen is clean enough to serve as the main entry point for future reading flow

## Notes

This task should prioritize clarity and simplicity over feature richness.
