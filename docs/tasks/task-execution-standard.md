# Task Execution Standard

## Task lifecycle
- Backlog: not started (`tasks/backlog`)
- In progress: active (`tasks/in-progress`)
- Done: completed and validated (`tasks/done`)

## Task format
Each task must include:
1. Goal
2. Scope and exclusions
3. Acceptance criteria
4. Validation commands
5. Notes for docs/ADR updates

## Sizing guidance
Prefer tasks that can be completed in one focused PR.
